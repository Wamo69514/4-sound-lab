4 SOUND LAB v6.0（ONBrake / Scratch Practice）

【使い方】
1. index.html をブラウザで開きます。ホーム画面アプリとして使うにはZIPを展開し、中身6ファイルをGitHub Pagesにアップロードしてください。
2. SOUND INPUT 1〜8で音を登録。NULLは自動抽選されません。
3. 入力欄の下で、各音の抽選倍率を設定（×0／×0.25／×0.5／×1／×2／×3／×5）。この数値は「相対的な出現しやすさ」で、個別音の絶対確率ではありません。×0でも手動選択はできます。
4. 連結ペア（例：キュ→ウ）は専用の欄に2つ登録。ペアの抽選倍率も設定できます。抽選時は2音連続、4音目にペアの先頭音は来ません。
5. BPMとフレーズを切り替える小節数（8〜128、8刻み）を選択。
6. TEMPO RAMPはOFF／小節ごと／フレーズごとを選択し、何小節or何フレーズごとに何BPM増えるか設定します。例：80BPM、8小節ごと、+5BPMの場合、8小節終了後85BPM、16小節終了後90BPMです。フレーズごとの場合は、画面で設定した「切替までの小節数」を1フレーズと数えます。300BPMが上限です。停止すると開始BPMに戻ります。
7. フレーズの文字を直接タップして編集、もしくは各マス右端の▼で登録した音を選択。ペアを選べばもう片方が隣に自動的に入ります。
8. iPhone/iPadではキーボードのEnter/Done、欄外タップ、右下の「⌨ 入力完了 ✓」ボタンで入力を終了できます。iOS実機での動作は環境により異なる場合があります。
9. 生成方式は完全ランダム／半ランダム／固定（変化なし）の3種類。固定モードを選ぶと画面の4行がそのまま維持され、小節切替でActiveだけ移動します。自動抽選されないのでSaveは不要。固定中はReset再抽選が無効になりますが、各マスの編集やSave、ライブラリ読み込みは可能です。BPM RAMPやPauseも使えます。
10. Saveはその行のみライブラリに登録し、固定します。ライブラリの読み込み先は行4です。JSONでバックアップと復元ができます。

【互換性】
v2〜v5の端末内の保存内容を移行します。同じWebサイト（GitHub Pages）のURLで開くことが必要です。
更新前にライブラリのJSONバックアップを作成してください。別のブラウザや端末とは自動同期されません。
GitHub Pagesの公開URLにアップロード後、公開側への反映には時間がかかる場合があります。
キャッシュ管理ファイル sw.js は v6.0 に更新済みです。通常はホーム画面アプリの再登録不要です。

【使用上の注意】
メトロノームはWeb Audioでクリック音を生成。BPM RAMP中も拍のタイミングを追従します。
端末のロック画面やバックグラウンドでは音が止まることがあります。実機iOSの音声・キーボード動作については未検証です。
ライブラリはブラウザのlocalStorageに格納。サイトデータの削除で消える場合があります。
