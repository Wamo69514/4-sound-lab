4 SOUND LAB v3.1 / 2026-10-18

■ 今回の新機能
- 4行のフレーズをタップすると開始行を選べます。Startでそこから開始（例：行3→4→1→2）。Pause中は行を選び直してResume可能。再生中はPause/Stopしてから変更。
- 選択中の開始行を端末へ保存。次回起動時にも維持します。
- SOUND INPUT 8枠。空欄（NULL）はランダム選択対象外。最低1音入力。
- 4音×4行のフレーズ。Activeは1→2→3→4→1と巡回。
- Saveした行だけライブラリ登録・固定。Savedを押すと固定解除。登録済みライブラリは残る。
- ライブラリから「行4へ読み込む」を押すと必ず第4行に挿入・固定。
- Resetを押すと4行すべてランダム再生成＋全行の固定解除（ライブラリは維持）。
- Pauseでメトロノーム＋カウントを一時停止。StartがResumeに変化、続きから再開。
- v2の保存データ・v2バックアップを読み込み可能。v3/v3.1 JSONバックアップも可能。

■ 継続機能
BPM 20〜300 / 8〜128小節を8小節刻み / 4拍子メトロノーム / 残り2小節でActive点滅。
データは使用端末のローカルストレージに保存されます。

■ GitHub Pagesへの更新手順
1. ZIPを展開し dj_phrase_trainer フォルダの中身を開く。
2. GitHub の既存リポジトリ (4-sound-lab) を開き、Add file > Upload files。
3. index.html, sw.js, manifest.webmanifest, README.txt をアップロードして既存ファイルを置き換え、Commit changes。
   アイコンの変更はないため、icon-192.pngとicon-512.pngの再アップロードは不要です。
4. 既存のホーム画面アイコンから起動できます。更新されない場合はSafariでGitHub PagesのURLを開き、再読み込みしてからアプリを再起動してください。
   注意: 「ホーム画面のアプリを削除」「Webサイトデータを消去」を先に実施しないでください。保存ライブラリが消える可能性があります。

■ データ互換性
v2と同じGitHub PagesのURLで更新すれば、v2のブラウザ保存状態を初回起動時にv3へ移行します。
ただしiPhone/iPadでSafariとホーム画面のアプリの保存領域が異なる場合があります。
更新前にv2のアプリで「バックアップを書き出す」を行っておくと安全です。
バックアップ読み込みはv2/v3両対応です。

■ 注記
画面が非表示になると自動でPause。復帰後にStart（Resume）をタップしてください。
メトロノーム再生は端末の音声設定やiOSの制限を受けます。
将来の自作ビート機能はまだ実装していません。
