4 SOUND LAB v4.0 / ONBrake Scratch Practice

【v4で追加】
・フレーズ内の各1音をタップ（クリック）すると、その場所を直接文字入力で編集できます。
・開始行の選択は各行右端の「LINE 01...04 / START」を押します。
・PHRASE MODE：完全ランダム（従来仕様）／半ランダム（前行から1音だけ変更）。
・半ランダムは最上段の4音を種として、2→3→4行目を順番に作成。4→1へ戻る際も、直前の4行目から1音変化させて続きます。
・「1行目から生成 ↗」ボタンで再生成して試し聴き・確認が可能。Startも選択中モードを使用します。
・半ランダム中、変更された音には水色の下線がつきます。
・保存済み行は固定を優先します（前行との1音差が成立しない場合があります）。
・保存済み行を手編集すると行の固定は解除され、ライブラリ内の元データは維持。編集後にSaveで新規保存してください。
・空白INPUTを抽選対象から除外。1音しか選べない場合は変化しないことがあります。

【従来からの機能】
8音INPUT、4行の4音フレーズ、BPM、8～128小節、メトロノーム、Pause/Stop/Reset、Start行選択、ライブラリへの保存と4行目への読み込み、JSONバックアップ。

【GitHub Pages更新】
1. v4 ZIPを解凍し、dj_phrase_trainerフォルダの中身6ファイルをすべて選択。
2. 既存GitHubリポジトリのルート（index.htmlがある場所）から Add file > Upload files。
3. 同じ名前のファイルをアップロードして Commit changes。Settings > Pagesは変更不要。
4. 数分後に公開URLをSafariで再読込。必要に応じてホーム画面アプリを終了して開き直してください。
5. 作業前にアプリの「バックアップを書き出す」でJSON保存を推奨。

【データ・制約】
旧v3/v2の保存データを新v4に初回移行します。端末ごとにデータは独立、同期なし。画面ロック中のメトロノーム動作は保証されません。
保存ライブラリはResetで消えません。v2/v3/v4形式のJSONをインポートできます。
